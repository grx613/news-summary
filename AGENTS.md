# Правила для агента

## Коммиты

- После каждой завершённой правки кода или текстов сразу делай `git commit`. Не копи изменения и не жди напоминания.
- Один коммит — одна законченная мысль. Несвязанные правки разноси по разным коммитам.
- Пуш в `origin` делай только по явной просьбе.
- Сообщение пиши по-русски, как в истории репозитория: короткая первая строка без точки, затем при необходимости абзац о том, зачем сделано, а не что изменено.
- Добавляй файлы поимённо (`git add <файлы>`), а не `git add -A`. `data/` и `.env` в `.gitignore`, их в коммит не тянем.
- Перед коммитом проверь синтаксис: `node --check` для изменённых `.js`.

## Проект

- Сервис работает как `news-summary.service` (systemd, порт 3000), домен `fire.bothub.chat`. Права на `systemctl` у пользователя нет: для перезапуска достаточно `kill` процесса `node server.js`, systemd поднимет его сам.
- Раздел `/charts` называется «Графики». Слова «Viz» и «Визуализация» посетителю не показываем. Внутреннее имя `VIZ` остаётся только в ключах кеша (`VIZ:USD-RUB`) и адресах `/ticker/viz/…`, его не менять.
- Тексты на сайте пишутся по-русски, переводы лежат в `lib/langs/en.js` и `lib/langs/es.js`. Ключ словаря — сам русский текст, поэтому при смене русской фразы меняй ключ во всех трёх местах.
